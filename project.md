# SWII Support AI Web Application

## 1. Project Overview

### Project Name
**SWII – AI-Powered Support Request and Customer Assistance Web Application**

### Project Description

Develop a modern, responsive web application called **SWII** where users can submit support questions, complaints, and service requests and receive automatic, helpful responses generated by an integrated Artificial Intelligence (AI) service.

The application must allow customers to submit their:

- Full Name
- Email Address
- Subject
- Detailed Complaint or Support Request

Once a request is submitted, the system must:

1. Save the support request in the Supabase database.
2. Send the request to an integrated AI service.
3. Analyze the user's complaint.
4. Generate a helpful and professional AI response.
5. Automatically categorize the issue.
6. Detect the urgency level.
7. Generate a short summary of the complaint.
8. Save the AI analysis and response.
9. Update the request status.
10. Display the request and AI response in the customer's dashboard.

The application must have a professional **orange and blue brand identity** and work smoothly on **mobile phones, tablets, laptops, and desktop computers**.

---

# 2. Project Objectives

The objectives of the SWII application are to:

- Provide an easy way for users to submit support requests.
- Reduce response time through AI-powered automation.
- Automatically generate helpful responses to customer complaints.
- Organize customer support requests in one central dashboard.
- Track the progress of each request.
- Automatically identify the category of a support issue.
- Automatically determine the urgency of a complaint.
- Summarize long customer complaints for easier review.
- Provide a clean and responsive user experience.
- Create an application that can be deployed using GitHub and Vercel.

# 15. AI Response Format

The application should ask the AI to return structured data.

Preferred format:

```json
{
  "response": "Helpful response to the customer",
  "category": "Technical Issue",
  "urgency": "Medium",
  "summary": "Short summary of the customer's problem"
}
```

The backend must validate the AI response.

If the AI returns invalid or incomplete data:

- Handle the error safely.
- Do not crash the application.
- Preserve the customer's original support request.
- Keep the request status as Pending if processing fails.
- Allow future retry functionality.

Do not expose raw AI API errors to the user.

# 16. AI Prompt Requirements

Create a strong server-side prompt for the AI.

The AI should be instructed to:

- Analyze the customer's request carefully.
- Generate a professional response.
- Be polite and empathetic.
- Provide useful next steps.
- Categorize the issue.
- Determine urgency.
- Summarize the issue.
- Avoid inventing information.
- Avoid claiming an action has been completed unless confirmed by the system.
- Return structured JSON only when requested.

Suggested instruction:

```text
You are an AI customer support assistant for SWII.

Analyze the customer's support request and provide:

1. A helpful, professional, and empathetic response.
2. The most appropriate issue category.
3. An urgency level: Low, Medium, High, or Critical.
4. A concise summary of the complaint.

Do not invent company policies, account information, actions, refunds, or technical fixes that have not been confirmed.

Return the result in valid JSON using this structure:

{
  "response": "string",
  "category": "string",
  "urgency": "Low | Medium | High | Critical",
  "summary": "string"
}
```
