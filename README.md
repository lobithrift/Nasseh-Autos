# Nasseh Autos - Premium Automobile Dealership & Automotive Services

Nasseh Autos is a premier automotive platform offering certified vehicle sales, car rental fleet bookings, multi-step workshop service scheduling, service status tracking, trade-in valuations, vehicle financing applications, and an interactive customer support assistant.

## Features

- **Vehicle Inventory & Sales**: Search and filter inventory by make, model, price range, body type, fuel type, transmission, and condition (Foreign Used / Tokunbo, Brand New, Locally Used).
- **Home Car Transition Slider**: Dynamic showcase of available vehicles with seamless sliding animations.
- **Car Rentals**: Rent premium sedans, SUVs, and luxury trucks with daily and weekly rates.
- **Workshop Service Booking & Tracking**: Multi-step booking flow with live reference ID status tracking across 9 repair stages.
- **Sell & Trade-In**: Instant online vehicle valuation form for cash payouts or trade-in credit.
- **Vehicle Financing**: Payment estimator and structured loan application system.
- **Customer Support & Live Chat**: Integrated AI customer support widget answering inquiry questions and connecting directly to WhatsApp (`07015199204`).
- **Secure Admin Portal**: `/admin` dashboard gated with email & password authentication (`nassehautos@gmail.com`) for managing inventory, service bookings, and leads.

## Technology Stack

- **Framework**: Next.js 14 (App Router), React, TypeScript
- **Styling**: Tailwind CSS, Lucide Icons
- **Data & Storage**: Supabase & local persistent fallback store
- **Deployment**: Vercel & GitHub

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open `http://localhost:3000` in your browser.
